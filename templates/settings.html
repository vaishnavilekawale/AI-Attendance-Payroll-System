Email Configuration
Configure SMTP settings in .env file for email functionality.
Required .env variables:
  • MAIL_SERVER
  • MAIL_PORT
  • MAIL_USE_TLS
  • MAIL_USERNAME
  • MAIL_PASSWORD
  • MAIL_DEFAULT_SENDER

For Gmail, use App Password instead of regular password.

Data Backup

Download a complete backup of your attendance database, employee documents, and captured face images as a single .zip file. Store it somewhere safe — a USB drive, network share, or cloud storage — separate from this computer.

The backup includes: instance/attendance.db (all attendance, payroll & employee records), uploads/ (profile photos, generated payslips), and dataset/ (captured face images). Trained face-recognition encodings are not included since they can always be regenerated from dataset/ via "Train AI" if ever needed.
